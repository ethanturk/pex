# Pex iOS Frontend — Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add an iOS target to Pex using Tauri v2's mobile support, reusing the existing Rust backend and adapting the Preact/Tailwind frontend for mobile.

**Architecture:** Tauri v2 compiles the Rust backend as a static library linked into a native iOS shell (Swift). The frontend runs in WKWebView, calling the same Tauri `invoke()` commands. The existing Rust code is shared 100% — only the frontend UI adapts for mobile. Two-tab layout: PRs (stack nav for the review workflow) and Settings (AI config, accounts, theme). iPad gets an adaptive multi-panel layout matching the desktop UI.

**Tech Stack:** Tauri v2 (mobile), Swift + SwiftUI (iOS shell, iOS 16.0+), Preact + TypeScript + Tailwind CSS (shared frontend), WKWebView

**Decisions:**
- Navigation: two-tab bar — PRs (single stack) + Settings (flat)
- Layout: adaptive — iPhone single-column, iPad multi-panel matching desktop
- Auth: PAT first (text field, same as desktop), OAuth deferred
- Network: network-only with SQLite speed cache (no offline mode)
- iPad multitasking: single-window for v1 (Slide Over covers reference use case)
- iOS floor: 16.0 (gets NavigationStack, avoids deprecated NavigationView)

## Implementation Phases

### Phase 1: iOS scaffold

`tauri ios init` generates the Xcode project. Wire `mobile_entry_point`, verify Rust compiles for `aarch64-apple-ios`, and get the blank webview launching in Simulator.

**Files:**
- Generate: `src-tauri/ios/` (Xcode project)
- Modify: `src-tauri/tauri.conf.json` — mobile config
- Verify: `src-tauri/src/lib.rs` — `#[cfg_attr(mobile, tauri::mobile_entry_point)]` already present

### Phase 2: Navigation shell

Two-tab SwiftUI app with NavigationStack (PRs) + Settings. The webview loads the Preact frontend and the tabs manage which view is shown.

**Files:**
- Create: `src-tauri/ios/Pex/App.swift`
- Create: `src-tauri/ios/Pex/PRsTab.swift`
- Create: `src-tauri/ios/Pex/SettingsTab.swift`
- Create: `src-tauri/ios/Pex/WebView.swift`

### Phase 3: Auth screen (mobile)

PAT entry adapted for mobile — compact form, paste-friendly, keyboard management. Same `login_pat` Tauri command, no Rust changes.

**Files:**
- Create: `src/components/AuthScreen.ios.tsx` (mobile-adapted, or responsive CSS in existing)

### Phase 4: PR list (mobile)

List → detail push navigation. Pull-to-refresh. Org/project picker presented as a bottom sheet. iPad shows list + detail side-by-side in adaptive layout.

**Files:**
- Modify: `src/app.tsx` → add mobile tab-aware routing
- Modify: `src/components/PRList.tsx` — responsive list items

### Phase 5: Diff viewer (mobile)

Server-rendered HTML diffs (unchanged from desktop) displayed in a mobile scroll view. Syntax highlighting from Rust `syntect` works identically. Swipe right on a file to mark viewed. File tree as a collapsible sheet on iPhone, sidebar on iPad.

**Files:**
- Modify: `src/components/DiffViewer.tsx` — responsive layout
- Modify: `src/components/FileTree.tsx` — sheet on iPhone, sidebar on iPad

### Phase 6: Commenting (mobile)

Inline comment input with iOS keyboard avoidance (`.ignoresSafeArea(.keyboard)` in Swift). Threaded reply UI adapted for narrow screens. Same ADO threads API via existing Tauri commands.

**Files:**
- Modify: `src/components/PRDetail.tsx` — comment input with keyboard-aware positioning
- Modify: `src-tauri/ios/Pex/WebView.swift` — keyboard avoidance

### Phase 7: AI review (mobile)

Review trigger button, progress bar, results inline — all adapted for narrow screens. The Rust review engine (`src-tauri/src/review/`) runs unchanged.

**Files:**
- Modify: `src/components/HunkReview.tsx` — responsive
- Modify: `src/components/ReviewPR.tsx` — responsive progress

### Phase 8: Polish & Store

Splash screen (LaunchScreen.storyboard), app icon (1024x1024), TestFlight distribution via Xcode Organizer, App Store metadata. `tauri ios build` produces the `.ipa`.

**Files:**
- Modify: `src-tauri/ios/Pex/Assets.xcassets` — app icon
- Create: `src-tauri/ios/Pex/LaunchScreen.storyboard`
